# Instructor's example scripts

The course instructor gave the class two example scripts. They are course material, so
they are **not distributed with this repository**:

- `scenario2_thyao_weekday_patterns.py`
- `scenario3_technical_reversal_events_3_periods.py`

Some tests compare this project's tools against those scripts (indicator values, event
counts, weekday statistics). To run them, place the two files in this folder, unmodified.
Without the files those tests are skipped; everything else runs as usual.

Git ignores `*.py` in this folder, so the files stay local.
