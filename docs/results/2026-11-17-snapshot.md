Notes

- **Stocks end one trading day before the indices.** At build time Yahoo returned the
  Monday 2026-11-16 bar for the indices but not for any stock. Tools cut every series at
  the requested date, so this only matters for a request whose end is 2026-11-16 or later.
- Two reference stocks (ORGE, ANELE) were added to the Construction group during this
  sprint so that the group reaches the minimum size; both returned full history.
- Each series has a content hash in `manifest.json`; two builds with identical data give
  identical hashes, so a silent revision by the source is detectable.
- **Hash method changed on 2026-11-17.** The first build hashed the in-memory frame in
  a way that did not survive the Parquet round trip, so `snapshot verify` reported every
  series as changed although no file had been touched. The hash now covers the dates as
  text and the values as 64-bit floats; the manifest of this snapshot was recomputed from
  the stored files (`hash_note` in `manifest.json`). `uv run python -m
  bist_harness.data.snapshot verify` now reports a match.
